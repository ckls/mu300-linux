# 发布内容中的旧 VPN 集成清理

2026-10-29 按用户要求清理项目自身已经不提供的旧入口，不根据关键词删改第三方主题。

- 删除旧控制脚本、OpenWrt/systemd 服务、配置示例及仅为这些功能使用的下载脚本和测试。
- 删除终端菜单、服务列表、看板快照、RPC/action 中的旧入口和状态探测。
- 构建器不再下载或挂载这些旧组件。保留归档排除检查，防止旧输入重新带入可执行程序。
- 清理空的 LuCI 菜单父节点；另有用户插件提供子菜单时保留父节点，并更新 APK 文件
  校验记录。归档清理两遍流式读取，不展开另一份完整 rootfs。
- 升级继续保留用户插件和配置；DNS 修复保留端口归属、实际监听、其他解析器和用户确认
  等约束，移除对已删除内置服务的启用标志判断。自定义解析器占用端口的回归仍通过。

Aurora 自带样式和图标不删除、不修改。通用协议支持、WireGuard 等内核配置、第三方
软件版权信息和用户自行安装的功能不在此次清理范围内。没有修改既有发布包，也不保证
网盘审核结果；这些源代码变更需下一次正常组包才进入新固件。

回归包括归档排除和主题保留、菜单及 APK 文件记录、用户包/DNS 升级、实际 ucode
看板快照及修改过的 shell 脚本语法检查；不访问实机。
