# MU300 系列更新说明（2026-10-24～25）

适用 MU300、F50、V50、U30 Air；提供 7.2.8 和 6.18.54 两种内核包。

- **补齐随包 Diff Studio**：完整解压即可使用 Windows、Apple Silicon 或 Python 入口，和安装器共用已有后端，不重复放入 boot、rootfs 或另一套运行环境。
- **差异更新更方便**：可自动保存新版版本摘要，之后用旧摘要加新完整包生成补丁；支持摘要导入、导出，减少保留和反复读取旧完整包的需要。
- **修复看板旧错误和串卡数据**：蜂窝读取恢复后及时清除之前的失败提示；慢数据、部分读取和切卡状态分别处理，避免上一张 SIM 的旧数据覆盖当前显示。
- **减少后台唤醒**：LED、温控和诊断任务更多按现有事件和实际时间点执行，保留 U30 Air 充电指示和无线行为。
- **CPU 设置更可靠**：支持机型可保存 CPU0 休眠选择；正常断电后保留用户已确认的电压设置，同时保留首次应用失败时的恢复机制。
- **U30 Air 充电修复**：对齐原厂充电器检测交接与 PD 接收时序，改善普通充电器被误判为电脑供电、偶发低功率的问题。
- **Mac 安装体验**：改善安装包目录识别，并明确完整包更新的兼容范围。

**本次快速补包只增加 Diff Studio 和说明，系统镜像、内核及原 Magisk 载荷保持原样；上述系统修复已在 2026-10-25 固件中。**
